# Contributing

Thank you for helping improve Corteza translations.

## Translate on Crowdin
Join the [Crowdin project](https://crowdin.com/project/corteza) to start translating.

## Request a New Language
Use the "Request New Language" button in Crowdin if your language is not supported.

## Sync Schedule
Pending translation strings will be approved before every release. Approved strings are synced to this repository automatically.
