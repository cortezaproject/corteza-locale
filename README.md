**Corteza Locale** provides the centralized repository for all corteza translations.

Follow the [Developer's guide](DEV.md) and [Internationalisation documentation](https://docs.cortezaproject.org/corteza-docs/2024.9/integrator-guide/i18n/static.html) to configure your local development environment with translations.
